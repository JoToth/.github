# Code of Conduct

## Our Commitment

We are committed to providing a respectful, inclusive, and harassment-free environment for everyone. All contributors are expected to communicate constructively and treat others with respect.

## Expected Behavior

* Be respectful and considerate in all interactions
* Use welcoming and inclusive language
* Provide constructive feedback
* Focus on what is best for the project
* Show empathy toward other contributors

## Unacceptable Behavior

The following behaviors are not tolerated:

* Abusive, offensive, or insulting language
* Harassment, discrimination, or personal attacks
* Trolling, deliberate provocation, or disruptive behavior
* Public or private harassment
* Any conduct that is inappropriate in a professional environment

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Violations may result in actions including:

* Warning
* Removal of content (issues, comments, pull requests)
* Temporary or permanent ban from the project

## Reporting

If you experience or witness unacceptable behavior, please report it to the project maintainers.

All reports will be handled confidentially and reviewed fairly.

## Scope

This Code of Conduct applies to all project spaces, including:

* Issues
* Pull requests
* Discussions
* Any other community interaction

## Final Notes

By participating in this project, you agree to abide by this Code of Conduct.
