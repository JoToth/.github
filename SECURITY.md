# Security Policy

## Scope

This repository contains community policies and templates, not executable software. For vulnerabilities in another JoToth repository, use that repository’s security reporting instructions.

## Private reporting

Use **Security → Report a vulnerability** in the affected repository if private vulnerability reporting is enabled. Do not disclose vulnerabilities, credentials, or sensitive details in public issues or discussions.

If private reporting is not available, open a public issue **without any vulnerability details** requesting a private contact route. The maintainer must arrange a private channel before any sensitive information is sent.

This document does not assert that private vulnerability reporting has already been enabled, or promise a response SLA.
