# Support

For questions about the shared JoToth community policies, open an issue in [this repository](https://github.com/JoToth/.github/issues) **if issues are enabled**. For build, installation, usage, or project-specific questions, use the affected repository's README and issue tracker.

Do not include passwords, private tokens, personal information, or undisclosed vulnerability details in public issues. See [Security Policy](SECURITY.md) for security reporting guidance.

Support is community-maintained; no response-time guarantee is provided.
