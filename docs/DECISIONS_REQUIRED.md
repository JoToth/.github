# Publication checks

The repository license is **BSD 3-Clause** (`BSD-3-Clause`), approved by the repository owner. This license is not automatically inherited by other repositories.

Before declaring 100% compliance, verify on GitHub:

- [ ] `.github` repository is public and owned by `JoToth`.
- [ ] Repository description, issues and pull requests are configured as intended.
- [ ] GitHub Community Standards UI recognizes the applicable files.
- [ ] Private vulnerability reporting is enabled for the repositories where it is offered, or an actual verified confidential channel is published.
- [ ] Code of Conduct reporting route is confidential and actionable (not merely a public issue).
- [x] Owner approves BSD 3-Clause licensing.
- [ ] Owner confirms a confidential Code of Conduct reporting process.
- [ ] Default-file inheritance is tested from another JoToth repository without local overrides.

Local file checks cannot verify these settings. Do not claim a live 100% score before these checks pass.
